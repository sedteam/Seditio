Seditio Core JS Showcase sedjs API

Çekirdek bileşenlerinin kapsamlı etkileşimli vitrini: formlar, Sürükle ve Bırak sıralama, sekmeler, modal pencereler, açılır bilgi panelleri, grafikler, dosya yükleme ve araçlar.

Görsel Tema:
1. Form Öğeleri ve Bileşenleri Forms & Inputs

1.1. Özel Seçim Kutusu (sedjs.select)

3 genişlik modu (içeriğe göre otomatik, sabit genişlik, %100 genişleme), optgroup gruplandırma ve aramalı Multi-Select desteği.

Otomatik genişlik (içeriğe göre):
HTML:<select name="status" class="sed-select">...</select> PHP:sed_selectbox($selected, 'status', $options_array, false)
Sabit genişlik (260px):
HTML:<select name="cat" class="sed-select" style="width: 260px;" data-search="true">...</select> PHP:sed_selectbox($selected, 'cat', $options, false, false, '', '', '', array('style' => 'width: 260px;'))
%100 kapsayıcı genişliği (Block):
HTML:<select name="status_block" class="sed-select sed-select-block">...</select> PHP:sed_selectbox($selected, 'status_block', $options, false, false, '', '', 'sed-select-block')
Çoklu seçim (Multi-Select):
HTML:<select name="groups[]" class="sed-select" multiple data-search="true" data-width="340px">...</select>

1.2. Anahtarlar / Geçiş Düğmeleri (.sed-switch)

Standart onay kutuları yerine akıcı geçiş anahtarları.

Standart anahtar:
HTML:<label class="sed-switch"><input type="checkbox" name="allow_comments" checked><span class="sed-switch-slider"></span><span>Metin</span></label> PHP:sed_checkbox('allow_comments', 1, 'yes') // $cfg['yesno_type'] = 'switch' durumunda
Kompakt anahtar (sm):
HTML:<label class="sed-switch sed-switch-sm"><input type="checkbox"><span class="sed-switch-slider"></span></label>
Devre dışı anahtar (Disabled):
HTML:<label class="sed-switch"><input type="checkbox" disabled checked><span class="sed-switch-slider"></span></label>

1.3. Parola Görünürlüğü ve Hızlı Temizleme (sedjs.input)

Simgeye tıklayarak parolayı gösterme/gizleme ve anında metin temizleme düğmesi.

Parola (Göster / Gizle):
HTML:<input type="password" class="sed-password" value="..." style="width: 260px;"> PHP:sed_textbox('rpassword', '', 32, 64, false, 'password')
Temizleme düğmeli arama (Clear):
HTML:<input type="text" class="sed-clearable" value="..." style="width: 260px;"> PHP:sed_textbox('sq', $sq, 32, 64, false, 'text', 'sed-clearable')

1.4. Açılır Tarih ve Saat Seçici (sedjs.datepicker)

window.L üzerinden yerelleştirilmiş aylar/günler, hızlı "Bugün" / "Temizle" düğmeleri ve saat seçici takvim.

Tarih seçimi (Yalnızca Tarih):
HTML:<input type="text" class="sed-datepicker" value="2026-10-12"> PHP:sed_selectbox_date($timestamp, 'short') // $cfg['enable_sed_datepicker'] = 1 durumunda
Tarih ve saat seçimi (Tarih + Saat):
HTML:<input type="text" class="sed-datepicker" data-time="true" value="2026-10-12 14:30"> PHP:sed_selectbox_date($timestamp, 'long') // $cfg['enable_sed_datepicker'] = 1 durumunda

1.5. Etiket ve Anahtar Kelime Girişi (sedjs.tags)

Etkileşimli etiket girişi. Enter veya , ile ekleyin, × veya Backspace ile silin.

Sayfa anahtar kelimeleri:
HTML:<input type="text" class="sed-tags" value="seditio, cms, widgets"> PHP:sed_textbox('page_keywords', $keywords, 40, 255, false, 'text', 'sed-tags')

1.6. Bölümlenmiş Denetim (.sed-segmented)

Akıcı animasyonlu ve tek satırlık modern radyo düğmesi alternatifi.

Katalog görüntüleme modu:
HTML:<div class="sed-segmented"><input type="radio" name="view_mode" id="vm_1" checked><label for="vm_1">Izgara</label>...</div> PHP:sed_radiobox('view_mode', array('grid' => 'Izgara', 'list' => 'Liste'), 'grid')
Metin düzenleyici biçimi (sm):
HTML:<div class="sed-segmented sed-segmented-sm">...</div>

1.7. Özel Dosya Seçimi (sedjs.file)

3 genişlik modu (otomatik, sabit 350px, %100 genişleme), tekli ve çoklu seçim ile Sürükle-Bırak desteği.

Otomatik genişlik (inline-flex):
HTML:<input type="file" class="sed-file" data-file="true"> PHP:sed_filebox('userfile', 'file', false)
Sabit genişlik (350px):
HTML:<input type="file" class="sed-file" data-file="true" style="width: 350px;"> PHP:sed_filebox('userfile', 'file', false, '', false, array('style' => 'width: 350px;'))
%100 kapsayıcı genişliği (Block):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true"> PHP:sed_filebox('userfile', 'file sed-file-block', false)
Çoklu dosya yükleme (Multiple):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true" multiple> PHP:sed_filebox('userfile[]', 'file sed-file-block', true)

1.8. Sayı Artırıcı / Adım Denetimi (sedjs.stepper)

min, max ve step niteliklerine tam uyumlu entegre artırma/azaltma düğmeleri.

Sayfa başına kayıt sayısı:
HTML:<input type="number" class="sed-stepper" value="25" min="5" max="100" step="5"> PHP:sed_textbox('maxrows', 25, 6, 4, false, 'number', 'sed-stepper')
2. Liste ve Tabloların Sürükle-Bırak Sıralaması sedjs.sortable

2.1. Y Ekseni Sabitlemeli Sıralanabilir Liste (sedjs.sortable)

⠿ tutamacını fareyle sürükleyerek öğeleri yeniden sıralayın. Sıra update() geri çağrısıyla anında güncellenir.

  • ⠿Madde 1: Ana sayfa ve başlık afişi
    Sıra: 1
  • ⠿Madde 2: Ürün kataloğu
    Sıra: 2
  • ⠿Madde 3: Müşteri yorumları
    Sıra: 3
  • ⠿Madde 4: İletişim bilgileri
    Sıra: 4
JS:sedjs.sortable(document.querySelector('#sortable_single'), { handle: '.drag-handle', axis: 'y', update(e, ui) { /* Yeni sırayı AJAX ile kaydet */ } });

2.2. Bağlantılı Listeler (Kanban / connectWith)

İki bağımsız sütun arasında kartları sürükleyip bırakın.

Devam Edenler (ToDo) Sütun 1
  • ⠿Site temalarını güncelle
  • ⠿VT önbelleğini yapılandır
  • ⠿PFS erişim izinlerini denetle
Tamamlananlar (Done) Sütun 2
  • ⠿SedFile modülünü geliştir
  • ⠿SedSelect bileşenini iyileştir
JS:sedjs.sortable(container1, { connectWith: '.kanban-sortable', handle: '.drag-handle' }); JS:sedjs.sortable(container2, { connectWith: '.kanban-sortable', handle: '.drag-handle' });
3. Sekmeler, Spoylerler ve Akordeonlar Navigation & Disclosure

3.1. Etkileşimli Sekmeler (sedjs.sedtabs)

Sayfayı yenilemeden içerik bölümleri arasında geçiş yapın.

  • Genel Bilgiler
  • SEO ve Meta Etiketleri
  • Gelişmiş
Sekme 1: Makale düzenleme veya sistem yapılandırmasının ana alanları burada yer alır.
Sekme 2: Meta Başlık, Meta Açıklama ve kurallı sayfa URL alanları.
Sekme 3: Kullanıcı grubu izinleri ve gelişmiş görüntüleme seçenekleri.
HTML:<div class="sedtabs"><ul class="tabs"><li><a href="#tab1" class="selected">Sekme 1</a></li>...</ul></div> JS:sedjs.sedtabs({ containerClass: 'sedtabs', eventType: 'click', selectedClass: 'selected' });

3.2. Otomatik Kapanan Akordeon (sedjs.accordion)

Akordeon panelleri. Yeni bir panel açıldığında önceki açık olan otomatik olarak kapanır.

Bölüm 1: Sympfy Tema Ayarları
Site temasının renk paleti, yazı tipleri ve ana düzen genişliği ayarları.
Bölüm 2: Çekirdek Modülleri ve Güvenlik
İki faktörlü kimlik doğrulama, kullanıcı parolası şifreleme ve spam koruma yönetimi.
Bölüm 3: Önbelleğe Alma ve Performans
Dahili sayfa önbelleği yapılandırması, statik CSS/JS sıkıştırması ve otomatik yükleme ayarları.
HTML:<div class="sedaccordion"><div class="accordion-item"><div class="accordion-header">...</div>...</div></div> JS:sedjs.accordion();

3.3. Açılır Kapanır Kutu (sedjs.spoiler)

Başlığa veya düğmeye tıklayarak gizli bloğu açın.

Sunucu ve PHP Teknik Bilgileri
PHP Version: 8.4.x | MySQL Engine: InnoDB | CMS Seditio: v186
HTML:<div class="spoiler"><div class="spoiler-title">...</div><div class="spoiler-content">...</div></div> JS:sedjs.spoiler();

3.4. Sistem Bildirimleri ve Uyarılar (sedjs.closealert)

Kapatma düğmesine tıklandığında akıcı şekilde kaybolan sistem bildirimleri.

Başarılı: Bölüm yapısı değişiklikleri veritabanına başarıyla kaydedildi!
Uyarı: Güncellemeye geçmeden önce veritabanı yedeği almanız önerilir.
HTML:<div class="alert alert-success"><span>Metin</span><button class="close">&times;</button></div> JS:sedjs.closealert();

XTemplate SE Etiketleri Kılavuzu

HTML:<button data-sed-popover-trigger data-sed-popover-target="my_pop">Aç</button> JS:sedjs.popover.init(document);

7. Resim Yükleyici ve Yöneticisi sedjs.imageUpload

PFS, galeriler ve ürün vitrinleri için gecikmeli resim yükleme bileşeni. Masaüstünden sürükle-bırak, yerel önizleme oluşturma, küçük resimleri sıralama (sedjs.sortable entegreli) ve bağlantıdan resim ekleme desteği.

8. Akıllı Otomatik Tamamlama ve Canlı Arama Autocomplete.js

8.1. Vurgulanan Sonuçlarla Canlı Arama (Autocomplete)

Giriş alanları (etiketler, yazarlar, kategoriler, ülkeler) için Vanilla JS otomatik tamamlama. Yerel dizi veya AJAX, klavye ok tuşlarıyla gezinme ve bulunan harfleri vurgulamayı destekler.

HTML:<input type="text" id="site_search" placeholder="Ara..."> JS:new Autocomplete(document.getElementById('site_search'), { lookup: [ { value: 'Haberler (News)', data: 'news' }, { value: 'Sayfalar ve Makaleler (Pages)', data: 'pages' }, { value: 'Forumlar (Forums)', data: 'forums' } ], minChars: 1, onSelect(suggestion) { logEvent('autocomplete:select', suggestion.value); } });
