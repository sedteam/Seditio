Seditio Core JS Showcase sedjs API

Comprehensive interactive showcase of core components: forms, Drag & Drop sorting, tabs, modal windows, popovers, charts, image uploading, and utilities.

Visual Theme:
1. Form Elements & Widgets Forms & Inputs

1.1. Custom SelectBox (sedjs.select)

3 width modes (auto fit by content, fixed width, 100% block expansion), optgroup support, and searchable Multi-Select.

Auto width (by content):
HTML:<select name="status" class="sed-select">...</select> PHP:sed_selectbox($selected, 'status', $options_array, false)
Fixed width (260px):
HTML:<select name="cat" class="sed-select" style="width: 260px;" data-search="true">...</select> PHP:sed_selectbox($selected, 'cat', $options, false, false, '', '', '', array('style' => 'width: 260px;'))
100% container width (Block):
HTML:<select name="status_block" class="sed-select sed-select-block">...</select> PHP:sed_selectbox($selected, 'status_block', $options, false, false, '', '', 'sed-select-block')
Multiple selection (Multi-Select):
HTML:<select name="groups[]" class="sed-select" multiple data-search="true" data-width="340px">...</select>

1.2. Switches / Toggles (.sed-switch)

Smooth toggles replacing standard checkboxes.

Standard toggle:
HTML:<label class="sed-switch"><input type="checkbox" name="allow_comments" checked><span class="sed-switch-slider"></span><span>Text</span></label> PHP:sed_checkbox('allow_comments', 1, 'yes') // with $cfg['yesno_type'] = 'switch'
Compact toggle (sm):
HTML:<label class="sed-switch sed-switch-sm"><input type="checkbox"><span class="sed-switch-slider"></span></label>
Disabled toggle:
HTML:<label class="sed-switch"><input type="checkbox" disabled checked><span class="sed-switch-slider"></span></label>

1.3. Password Visibility & Quick Clear (sedjs.input)

Show/hide password on icon click and instant text clearing button.

Password (Show / Hide Password):
HTML:<input type="password" class="sed-password" value="..." style="width: 260px;"> PHP:sed_textbox('rpassword', '', 32, 64, false, 'password')
Search with clear button (Clear):
HTML:<input type="text" class="sed-clearable" value="..." style="width: 260px;"> PHP:sed_textbox('sq', $sq, 32, 64, false, 'text', 'sed-clearable')

1.4. Popup Date & Time Picker (sedjs.datepicker)

Calendar with localized months/days from window.L, quick "Today" / "Clear" buttons, and optional time selector.

Date selection (Date only):
HTML:<input type="text" class="sed-datepicker" value="2026-10-12"> PHP:sed_selectbox_date($timestamp, 'short') // with $cfg['enable_sed_datepicker'] = 1
Date and time selection (Date + Time):
HTML:<input type="text" class="sed-datepicker" data-time="true" value="2026-10-12 14:30"> PHP:sed_selectbox_date($timestamp, 'long') // with $cfg['enable_sed_datepicker'] = 1

1.5. Tags & Keyword Input (sedjs.tags)

Interactive chip input. Add tags with Enter or ,, remove with × or Backspace.

Page keywords:
HTML:<input type="text" class="sed-tags" value="seditio, cms, widgets"> PHP:sed_textbox('page_keywords', $keywords, 40, 255, false, 'text', 'sed-tags')

1.6. Segmented Control (.sed-segmented)

Sleek single-row replacement for native radio buttons with smooth active pill animation.

Catalog display mode:
HTML:<div class="sed-segmented"><input type="radio" name="view_mode" id="vm_1" checked><label for="vm_1">Grid</label>...</div> PHP:sed_radiobox('view_mode', array('grid' => 'Grid', 'list' => 'List'), 'grid')
Text editor format (sm):
HTML:<div class="sed-segmented sed-segmented-sm">...</div>

1.7. Custom File Input (sedjs.file)

3 width modes (auto width, fixed 350px, 100% block expansion), single/multiple selection, and Drag & Drop file dropping.

Auto width (inline-flex):
HTML:<input type="file" class="sed-file" data-file="true"> PHP:sed_filebox('userfile', 'file', false)
Fixed width (350px):
HTML:<input type="file" class="sed-file" data-file="true" style="width: 350px;"> PHP:sed_filebox('userfile', 'file', false, '', false, array('style' => 'width: 350px;'))
100% container width (Block):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true"> PHP:sed_filebox('userfile', 'file sed-file-block', false)
Multiple file upload (Multiple):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true" multiple> PHP:sed_filebox('userfile[]', 'file sed-file-block', true)

1.8. Number Stepper (sedjs.stepper)

Integrated increment and decrement controls strictly respecting min, max, and step attributes.

Items per page:
HTML:<input type="number" class="sed-stepper" value="25" min="5" max="100" step="5"> PHP:sed_textbox('maxrows', 25, 6, 4, false, 'number', 'sed-stepper')

  • General Info
  • SEO & Meta Tags
  • Advanced

Accordion panels. Opening a new panel automatically collapses the previously opened one.

Section 1: Sympfy Theme Settings

Section 2: Core Modules & Security
Two-factor authentication management, user password hashing, and anti-spam protection.
Section 3: Caching & Performance
Internal page caching configuration, static CSS/JS resource compression, and autoloading options.
HTML:<div class="sedaccordion"><div class="accordion-item"><div class="accordion-header">...</div>...</div></div> JS:sedjs.accordion();
