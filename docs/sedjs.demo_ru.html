Seditio Core JS Showcase sedjs API

Полная интерактивная витрина компонентов ядра: формы, Drag & Drop сортировка, вкладки, модальные окна, поповеры, графики, загрузка файлов и утилиты.

Тема оформления:
1. Элементы и виджеты форм Forms & Inputs

1.1. Кастомный SelectBox (sedjs.select)

3 варианта управления шириной (авторасчёт по содержимому, фиксированная ширина, 100% растяжение), а также группировка и Multi-Select.

Автоширина (по контенту):
HTML:<select name="status" class="sed-select">...</select> PHP:sed_selectbox($selected, 'status', $options_array, false)
Фиксированная ширина (260px):
HTML:<select name="cat" class="sed-select" style="width: 260px;" data-search="true">...</select> PHP:sed_selectbox($selected, 'cat', $options, false, false, '', '', '', array('style' => 'width: 260px;'))
100% ширина контейнера (Block):
HTML:<select name="status_block" class="sed-select sed-select-block">...</select> PHP:sed_selectbox($selected, 'status_block', $options, false, false, '', '', 'sed-select-block')
Множественный выбор (Multi-Select):
HTML:<select name="groups[]" class="sed-select" multiple data-search="true" data-width="340px">...</select>

1.2. Переключатели Switch / Toggle (.sed-switch)

Плавные тоглы вместо стандартных чекбоксов.

Стандартный тогл:
HTML:<label class="sed-switch"><input type="checkbox" name="allow_comments" checked><span class="sed-switch-slider"></span><span>Текст</span></label> PHP:sed_checkbox('allow_comments', 1, 'yes') // при $cfg['yesno_type'] = 'switch'
Компактный тогл (sm):
HTML:<label class="sed-switch sed-switch-sm"><input type="checkbox"><span class="sed-switch-slider"></span></label>
Отключенный (Disabled):
HTML:<label class="sed-switch"><input type="checkbox" disabled checked><span class="sed-switch-slider"></span></label>

1.3. Глазок для паролей и быстрая очистка (sedjs.input)

Показ/скрытие пароля по клику на иконку и кнопка мгновенного стирания текста.

Пароль (Show / Hide Password):
HTML:<input type="password" class="sed-password" value="..." style="width: 260px;"> PHP:sed_textbox('rpassword', '', 32, 64, false, 'password')
Поиск с кнопкой очистки (Clear):
HTML:<input type="text" class="sed-clearable" value="..." style="width: 260px;"> PHP:sed_textbox('sq', $sq, 32, 64, false, 'text', 'sed-clearable')

1.4. Всплывающий Date & Time Picker (sedjs.datepicker)

Календарь с локализацией месяцев/дней из window.L, быстрыми кнопками «Сегодня» / «Очистить» и временем.

Выбор даты (Date only):
HTML:<input type="text" class="sed-datepicker" value="2026-10-12"> PHP:sed_selectbox_date($timestamp, 'short') // при $cfg['enable_sed_datepicker'] = 1
Выбор даты и времени (Date + Time):
HTML:<input type="text" class="sed-datepicker" data-time="true" value="2026-10-12 14:30"> PHP:sed_selectbox_date($timestamp, 'long') // при $cfg['enable_sed_datepicker'] = 1

1.5. Ввод тегов и ключевых слов (sedjs.tags)

Интерактивный ввод чипов. Ввод по Enter или ,, удаление по × или Backspace.

Ключевые слова страницы:
HTML:<input type="text" class="sed-tags" value="seditio, cms, widgets"> PHP:sed_textbox('page_keywords', $keywords, 40, 255, false, 'text', 'sed-tags')

1.6. Сегментированный переключатель (.sed-segmented)

Стильная замена нативным радиокнопкам в одну строку с анимацией активного сегмента.

Режим отображения каталога:
HTML:<div class="sed-segmented"><input type="radio" name="view_mode" id="vm_1" checked><label for="vm_1">Сетка</label>...</div> PHP:sed_radiobox('view_mode', array('grid' => 'Сетка', 'list' => 'Список'), 'grid')
Формат редактора текста (sm):
HTML:<div class="sed-segmented sed-segmented-sm">...</div>

1.7. Кастомный выбор файлов (sedjs.file)

3 варианта ширины (автоширина, фиксированная 350px, 100% растяжение), а также одиночный и множественный выбор с поддержкой Drag & Drop.

Автоширина (inline-flex):
HTML:<input type="file" class="sed-file" data-file="true"> PHP:sed_filebox('userfile', 'file', false)
Фиксированная ширина (350px):
HTML:<input type="file" class="sed-file" data-file="true" style="width: 350px;"> PHP:sed_filebox('userfile', 'file', false, '', false, array('style' => 'width: 350px;'))
100% ширина контейнера (Block):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true"> PHP:sed_filebox('userfile', 'file sed-file-block', false)
Мультизагрузка файлов (Multiple):
HTML:<input type="file" class="sed-file sed-file-block" data-file="true" multiple> PHP:sed_filebox('userfile[]', 'file sed-file-block', true)

1.8. Числовой счетчик (sedjs.stepper)

Интегрированные кнопки инкремента и декремента со строгим соблюдением атрибутов min, max, step.

Количество записей на страницу:
HTML:<input type="number" class="sed-stepper" value="25" min="5" max="100" step="5"> PHP:sed_textbox('maxrows', 25, 6, 4, false, 'number', 'sed-stepper')
2. Drag & Drop сортировка списков и таблиц sedjs.sortable

2.1. Сортируемый список с фиксацией по оси Y (sedjs.sortable)

Перетаскивайте элементы мышью за ручку ⠿. Порядок обновляется на лету с коллбэком update().

  • ⠿Пункт 1: Главная страница и баннер
    Порядок: 1
  • ⠿Пункт 2: Каталог продукции
    Порядок: 2
  • ⠿Пункт 3: Отзывы клиентов
    Порядок: 3
  • ⠿Пункт 4: Контактная информация
    Порядок: 4
JS:sedjs.sortable(document.querySelector('#sortable_single'), { handle: '.drag-handle', axis: 'y', update(e, ui) { /* Сохранение нового порядка через AJAX */ } });

2.2. Связанные списки (Kanban / connectWith)

Перетаскивание карточек между двумя независимыми колонками.

В работе (ToDo) Колонка 1
  • ⠿Обновить скины сайта

Выполнено (Done) Колонка 2

JS:sedjs.sortable(container1, { connectWith: '.kanban-sortable', handle: '.drag-handle' }); JS:sedjs.sortable(container2, { connectWith: '.kanban-sortable', handle: '.drag-handle' });
3. Вкладки, Спойлеры и Аккордеоны Navigation & Disclosure

3.1. Интерактивные вкладки (sedjs.sedtabs)

Переключение разделов контента без перезагрузки.

  • Основная информация
  • SEO & Метатеги
  • Дополнительно
Вкладка 1: Здесь размещаются основные поля формы редактирования статьи или конфигурации.
Вкладка 2: Поля для Meta Title, Meta Description и канонических URL адресов страницы.
Вкладка 3: Настройки прав доступа групп пользователей и расширенные опции отображения.
HTML:<div class="sedtabs"><ul class="tabs"><li><a href="#tab1" class="selected">Таб 1</a></li>...</ul></div> JS:sedjs.sedtabs({ containerClass: 'sedtabs', eventType: 'click', selectedClass: 'selected' });

3.2. Аккордеон с авто-сворачиванием (sedjs.accordion)

Секции аккордеона. При открытии новой секции предыдущая автоматически сворачивается.

Секция 1: Настройки темы Sympfy
Параметры цветовой гаммы, шрифтов и ширины основного макета скина сайта.
Секция 2: Модули ядра и безопасность
Управление двухфакторной аутентификацией, шифрованием паролей пользователей и защитой от спама.
Секция 3: Кэширование и производительность
Конфигурация внутреннего кэша страниц, сжатия статических ресурсов CSS/JS и автозагрузки опций.
HTML:<div class="sedaccordion"><div class="accordion-item"><div class="accordion-header">...</div>...</div></div> JS:sedjs.accordion();

3.3. Спойлер (sedjs.spoiler)

Раскрытие скрытого блока по клику на кнопку/заголовок.

Технические сведения о сервере и PHP
PHP Version: 8.4.x | MySQL Engine: InnoDB | CMS Seditio: v186
HTML:<div class="spoiler"><div class="spoiler-title">...</div><div class="spoiler-content">...</div></div> JS:sedjs.spoiler();

3.4. Системные уведомления и алерты (sedjs.closealert)

Уведомления с плавным закрытием по клику на крестик.

Успех: Изменения в структуре разделов успешно сохранены в базе данных!
Внимание: Рекомендуется создать резервную копию базы данных перед обновлением.
HTML:<div class="alert alert-success"><span>Текст</span><button class="close">&times;</button></div> JS:sedjs.closealert();
4. Модальные окна и всплывающие панели Modal & Popover

4.1. Плавающее окно Seditio (sedjs.modal.open)

Полнофункциональное окно с перетаскиванием за шапку, ресайзом, сворачиванием в нижний трей и разворачиванием на весь экран.

4.2. Всплывающий поповер (sedjs.popover)

Информационная панель по клику на триггер с авто-закрытием при клике вне панели.

Справка по тегам XTemplate SE

Шаблонизатор Seditio поддерживает директивы <!-- BEGIN: BLOCK -->, циклы, фильтры и условные операторы IF / ELSE.

HTML:<button data-sed-popover-trigger data-sed-popover-target="my_pop">Открыть</button> JS:sedjs.popover.init(document);

6. Интерактивные графики и статистика SedChart.js

6.1. Линейный Canvas-график динамики (SedChart)

Легковесный (~2.5 KB) графический компонент на HTML5 Canvas без сторонних зависимостей. Поддерживает динамическое изменение масштаба, hover-тултипы и авто-ресайз.

HTML:<div id="my_chart" class="chart-container"></div> JS:const chart = new SedChart('my_chart', { labels: ['Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Вс'], values: [1250, 1890, 2430, 2120, 2800, 3450, 4100] }); JS:chart.setData(newLabels, newValues); // Динамическое обновление данных

8. Умный автокомплит и живой поиск Autocomplete.js

8.1. Живой поиск с подсветкой результатов (Autocomplete)

Vanilla JS автодополнение для полей ввода (теги, авторы, разделы, страны). Поддерживает локальный массив значений или AJAX, навигацию стрелками клавиатуры и подсветку найденных букв.

HTML:<input type="text" id="site_search" placeholder="Поиск..."> JS:new Autocomplete(document.getElementById('site_search'), { lookup: [ { value: 'Новости (News)', data: 'news' }, { value: 'Страницы и статьи (Pages)', data: 'pages' }, { value: 'Форум (Forums)', data: 'forums' } ], minChars: 1, onSelect(suggestion) { logEvent('autocomplete:select', suggestion.value); } });
