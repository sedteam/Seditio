# Что нового в Seditio 186

В данном документе представлен подробный технический обзор изменений, улучшений и исправлений, реализованных в **Seditio 186** по сравнению с предыдущей стабильной версией **Seditio 185**.

---

## 1. Ядро и системная архитектура

### Новый установщик системы (`system/setup/` вместо `system/install/`)
* Устаревшая директория `system/install/` полностью удалена из дистрибутива.
* Разработан современный пошаговый мастер установки (`system/setup/`) с компонентной архитектурой, адаптивным оформлением, валидацией окружения и поддержкой векторной графики (SVG).
* Основной роутинг `/install` в `system/index.php` и правила перезаписи URL (SEF URL) перенаправлены на контроллер `system/setup/setup.php`.
* Плагин проверки целостности системы `syscheck` обновлён для контроля файлов нового мастера установки.

### Выделение защиты от флуда в таблицу `sed_shield`
* Защита от флуда и атак типа hammer (anti-hammer flood protection) отвязана от механизма отслеживания онлайн-пользователей.
* Создана отдельная системная таблица `sed_shield` (`shield_ip`, `shield_lastseen`, `shield_hammer`, `shield_limit`, `shield_action`).
* Устаревшая таблица `sed_online` окончательно ликвидирована.

### Перевод Who's Online в модульный плагин (v3.0)
* Мониторинг присутствия пользователей на сайте полностью исключён из ядра и модулей пользователей (`users`).
* Функционал переписан в виде независимого плагина `whosonline` версии 3.0:
  * Внедрено собственное кэширование данных с настраиваемым временем жизни (TTL) в `plugins/whosonline/inc/whosonline.functions.php`.
  * Установка, удаление и обновление теперь выполняются через стандартный API расширений (`sed_plugin_install` / `sed_plugin_uninstall`).
  * Проверка доступности плагина стандартизирована через каноническую функцию `sed_plug_active('whosonline')`.

### Модернизация отправки HTTP-заголовков (`sed_sendheaders()`)
* Системный массив статусов `$cfg['msg_status']` расширен стандартными кодами ответов HTTP (200, 201, 204, 301, 302, 303, 304, 307, 308, 400, 401, 403, 404, 410, 500, 503).
* Функция `sed_sendheaders()` переработана: добавлена интеллектуальная обработка кодировок, передача пользовательских заголовков и управление заголовками `Cache-Control`.
* Прямые вызовы нативной функции PHP `header()` по всему движку (в AJAX-контроллерах, лентах RSS, Sitemap, Robots, ресайзере изображений и редиректах) переведены на использование системной функции `sed_sendheaders()`.
* Расширена поддержка HTTP-статусов редиректов в `sed_redirect()`, улучшена обработка канонических редиректов для ЧПУ-ссылок.

### Повышение надёжности защиты Anti-CSRF
* Реализован механизм сохранения предыдущего анти-CSRF токена сессии. Это предотвращает возникновение ложных ошибок «Wrong parameter in the URL» при работе пользователя в нескольких вкладках браузера или при повторной отправке данных форм.

### Глобальная локализация системных сообщений и инлайн-ошибки
* Языковой файл `system/lang/**/message.lang.php` теперь подключается глобально в `system/common.php`, делая массив `$L['msgXXX']` доступным во всех модулях и плагинах без повторных `require`.
* Динамические вычисления через `eval` в строках сообщений заменены на безопасный синтаксис плейсхолдеров `{username}` и `{num}` во всех языковых пакетах (RU, EN, TR).
* Ошибки авторизации (`msg151`–`msg154`) больше не вызывают редирект на отдельную служебную страницу `message.php`, а формируют список ошибок `$error_string` и отображаются инлайн непосредственно в блоке формы входа.

### Автоматическая регенерация кэша ЧПУ
* В `system/common.php` реализовано автоматическое фоновое пересоздание кэш-файла `datas/cache/sed_urls.php` при его отсутствии, что исключает сбои маршрутизации ЧПУ после очистки кэша или первоначальной настройки.

## 2. База данных и совместимость с PHP / MySQL

### Совместимость с MySQL 5.7+ и MySQL 8.0
* В функции `sed_sql_connect()` (`system/database.mysqli.php`) при установке соединения сессионная переменная `sql_mode` автоматически дополняется флагом `NO_ENGINE_SUBSTITUTION`, предотвращая прерывания при строгом режиме сервера.
* Переписаны SQL-запросы с несовместимыми комбинациями `DISTINCT` и `ORDER BY` (например, выборка категорий конфигурации в заголовке панели управления).
* Устранены конфликты группировки `GROUP BY` в соответствии со стандартом `ONLY_FULL_GROUP_BY` в модулях поиска по форумам, карты сайта, административной панели PFS и плагине `whosonline`.

### Совместимость с современными версиями PHP (8.1, 8.2, 8.3, 8.4+) при поддержке PHP 5.6
* В модуле регистрации (`modules/users/users.register.php`) и смежных скриптах проведена санитизация входных параметров для предотвращения `Deprecation warnings` при передаче `null` в функции `mb_strtolower()`, `str_replace()`, `mb_strlen()`.
* Защищена инициализация прав пользователя `user_auth` — переменная гарантированно инициализируется пустым массивом при отсутствии данных.
* Действие регистрации пользователей строго ограничено методом `POST`, исключая случайные ошибки валидации при прямом обращении методом `GET`.
* Синтаксис и конструкции ядра сохранены в строгом соответствии со стандартом PHP 5.6+ для бесшовной работы на любых хостинг-платформах.

## 3. Статические ресурсы, UI и фронтенд-архитектура

### Централизация системных ассетов в `system/assets/`
* Создана упорядоченная структура каталогов `system/assets/`:
  * `system/assets/js/` — системные JavaScript-библиотеки.
  * `system/assets/css/` — системные таблицы стилей.
  * `system/assets/fonts/` — системные шрифты и иконки.
* Основные скрипты ядра (`core.js`, `autocomplete.js`, `imageupload.js`) перенесены из устаревшей папки `system/javascript/`.
* Фирменный иконочный шрифт Seditio централизован в `system/assets/fonts/` с единым файлом `fonts.css`.
* Создан системный файл `system/assets/css/core.css`, аккумулирующий базовые стили элементов CMS (формы, всплывающие окна, модалки, иконки типов файлов PFS, юзер-панель), устраняя зависимость ядра от стилей конкретного скина админки.

### CSS Custom Properties (CSS-переменные) и отказ от устаревших префиксов
* Внедрена единая система CSS-переменных в `:root` (`--core-*`, `--admin-*`, `--sympfy-*`) для ядра, админ-скина и публичной темы Sympfy:
  * Базовая палитра цветов (primary, accents, границы, фоны, текст).
  * Стилизация компонентов (вкладки, аккордеоны, спойлеры, модальные окна, формы, бейджи, кнопки, прогресс-бары).
  * Состояния интерактивных элементов (hover, active, focus).
* Все хардкодные значения цветов приведены к переменным.
* Устаревшие вендорные префиксы градиентов (`-webkit-`, `-moz-`, `-ms-`, `-o-`) и фильтры под Internet Explorer заменены на стандартный CSS3 `linear-gradient()`.

### Модернизация модальных окон `sedjs.modal`
* Drag & Drop и масштабирование окон переведены на современный стандарт `Pointer Events` с защитой от залипания мыши при перемещении над `iframe`.
* Добавлена кнопка разворачивания окна на весь экран (Maximize).
* Реализован удобный докинг свернутых окон в левый нижний угол экрана (Minimize).
* Устаревшие растровые GIF-иконки и анимации ожидания заменены на векторные SVG-элементы и CSS-спиннеры.

### Новый виджет загрузки изображений (`sedjs.imageUpload`)
* В профиле пользователя устаревшие поля загрузки аватара, фотографии и подписи заменены на универсальный виджет `sedjs.imageUpload` в режиме плиток (`tiles`).
* Реализовано сохранение выбранных файлов без сброса формы при валидации, предпросмотр изображений и корректное удаление через скрытые маркеры `{prefix}_keep`.
* Стандартизирован вывод размеров файлов через функцию `sed_format_size()`.

## 4. Панель управления (Admin Panel)

### Комплексный редизайн главной страницы админки (Dashboard)
* Панель управления получила современную сетку виджетов и KPI-карточки со сводной статистикой сайта.
* Встроен лёгкий автономный графический движок `SedChart` (`system/assets/js/sedchart.js`), работающий на HTML5 Canvas без сторонних библиотек.
* Плагин быстрого просмотра `adminqv` полностью переписан на адаптивную Flexbox-верстку.
* Добавлены кнопки быстрого сервисного обслуживания: оптимизация базы данных и очистка кэша в один клик прямо с главного экрана.

### Интерактивная статистика посещаемости (`admin/hits`)
* Модуль статистики хитов переведён на интерактивный Canvas-график с динамическим переключением периодов (Год, Месяц, Неделя).

### Центр уведомлений в шапке (Topbar Notifications)
* В верхнюю панель админки встроен блок уведомлений с выпадающим списком событий, предупреждений и быстрой диагностикой состояния ключевых модулей.

### Управление расширениями
* В списке модулей и плагинов добавлено явное отображение совместимой версии ядра (например, `(186)`), исключающее путаницу между версией самого расширения и версией поддерживаемого движка.

## 5. Модули и встроенные плагины

### PFS (Персональное файловое хранилище)
* Реализована поддержка **вложенных папок**: папки PFS получили древовидную иерархию с поддержкой поля `pff_parentid`.
* Полностью исправлено функционирование общего файлового пространства сайта (Site File Space / SFS, `userid = 0`):
  * Устранено ошибочное отсечение параметров с нулевым значением в функции `sed_url()`, из-за которого файлы SFS ошибочно попадали в личное хранилище администратора.
  * Устранены предупреждения PHP 8 о неопределённом индексе `user_id` и некорректные хлебные крошки при работе с SFS.
* Оптимизирована генерация уникальных имён сохраняемых файлов.

### Управление меню (`sed_menu`)
* Добавлена возможность автоматического построения подменю на основе категорий страниц:
  * В таблицу меню добавлены поля `menu_cat` (категория-источник), `menu_cat_subcats` (включение подкатегорий) и `menu_cat_pages` (включение страниц в меню).
  * Интерфейс администрирования меню дополнен соответствующими селекторами и переключателями.

### Интернационализация (i18n)
* Добавлена поддержка мультиязычных заголовков и описаний структурных категорий сайта (хранение переводов в БД, редактирование в админ-панели и вывод на фронтенде).
* Внедрён динамический селектор языков `{HEADER_I18N_SELECTOR}`, сохраняющий текущий URI страницы при переключении языка и скрывающий активный язык.

### CKEditor
* Добавлен плагин `iconic` для вставки фирменных векторных иконок Seditio в текст статьи.
* Добавлен плагин `accordion` (интерактивные аккордеоны/скрывающийся контент) со стилизацией в ядре и полной локализацией на английский, русский и турецкий языки.

### Новые встроенные плагины
* **`cookienotice`**: плагин информирования посетителей об использовании cookie-файлов с адаптивным баннером в подвале сайта.
* **`contact`**: готовый модуль обратной связи с поддержкой валидации, капчи и интеграции с пользовательским соглашением.

### Поиск
* Реализована подсветка поисковых фраз в результатах выдачи и интеллектуальная генерация контекстных сниппетов текста вокруг совпадений.

### Капча (`sedcaptcha`)
* Добавлена проверка серверного метода HTTP-запроса, улучшена генерация и очистка графических контрольных кодов.

## 6. Миграция базы данных (`upgrade_185_186.php`)

Для плавного обновления системы со 185 на 186 версию разработан скрипт миграции `system/upgrade/upgrade_185_186.php`, выполняющий следующие операции:

1. **Таблица `sed_pfs_folders`**: добавление поля `pff_parentid int(11) NOT NULL DEFAULT '0'` и индекса `pff_userid_parent (pff_userid, pff_parentid)`.
2. **Таблица `sed_menu`**: добавление колонок `menu_cat`, `menu_cat_subcats` и `menu_cat_pages`.
3. **Таблица `sed_shield`**: создание новой таблицы для защиты от флуда.
4. **Таблица `sed_online`**: безопасное удаление устаревшей таблицы.
5. **Плагин `whosonline`**: автоматическая деинсталляция старой регистрации и установка плагина версии 3.0.
6. **Версия системы**: обновление значения версии в таблице `sed_stats` на `186`.
